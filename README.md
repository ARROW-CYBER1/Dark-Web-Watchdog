## Overview



**Dark Web Watchdog** is an AI-powered threat intelligence and leak detection platform that monitors compromised data marketplaces, detects personal and corporate leaks in real-time, and generates automated mitigation recommendations.

---

## Problem Addressed



Millions of critical assets—such as user credentials, API keys, payment card details, and proprietary corporate files—are regularly traded on dark web marketplaces. Key challenges include:

* Lack of awareness regarding personal and enterprise data leaks.


* High financial barriers preventing small businesses from accessing enterprise threat intelligence.


* Delayed incident detection and a lack of unified tools for monitoring, alert delivery, and AI guidance.



---

## Key Features



* **Asset Registration & Monitoring**: Tracks registered emails, domain names, phone numbers, employee usernames, and API keys against simulated dark web feeds and public breach databases.


* **AI Threat Analysis & Scoring**: Leverages NLP models for leak detection, threat classification, and calculating risk/confidence scores.


* **Automated Alerting**: Delivers real-time notifications via email, dashboard alerts, browser notifications, and optional Telegram integration.


* **AI Security Advisor**: Provides step-by-step incident containment checklists, including password reset triggers, MFA activation steps, and API key rotation workflows.


* **Companion Browser Extension**: A Chrome extension performing local Zero-Knowledge credential hashing (SHA-256), phishing checks, domain reputation scoring, and safe browsing warnings.


* **Threat Intelligence Dashboard**: Displays a visual threat timeline, risk scores, analytics, and downloadable PDF executive audit reports.
